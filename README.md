# Мафия

Консольная игра на Java по заданию «Мафия: роли, фазы, голосование».

## Возможности

- партия на 5 и более игроков;
- случайная раздача ролей;
- роли: мирный, мафия, комиссар, доктор, любовница;
- ночные действия и разрешение конфликтов;
- фазы партии: ночь, утро, обсуждение, голосование, казнь;
- личные знания каждого игрока;
- дневное голосование с перевесом и переголосованием при равенстве;
- условия победы мафии и города;
- журнал партии, который каждый игрок видит по-своему.

## Роли

| Роль | Что делает ночью |
|---|---|
| Мирный | Ничего |
| Мафия | Убивает выбранного игрока |
| Комиссар | Проверяет команду игрока |
| Доктор | Лечит выбранного игрока |
| Любовница | Блокирует ночное действие игрока |

## Ночные действия

Порядок разрешения:

1. Любовница блокирует действие выбранного игрока.
2. Доктор лечит выбранного игрока.
3. Комиссар проверяет команду игрока.
4. Мафия убивает выбранную жертву.

Конфликты:

- если доктор вылечил жертву мафии — игрок выживает;
- если доктор заблокирован — лечение не срабатывает;
- если комиссар заблокирован — проверка не выполняется;
- если мафия заблокирована — убийство не происходит.

## Голосование

- голосуют только живые игроки;
- побеждает кандидат с наибольшим числом голосов;
- при равенстве проводится переголосование между лидерами;
- если равенство повторилось — никто не казнён.

## Условия победы

- **Город** побеждает, если не осталось живых мафиози.
- **Мафия** побеждает, если живых мафиози не меньше, чем живых представителей города.

## Структура проекта

```text
src/main/java/com/mafia
├── Main.java                  # запуск игры и цикл партии
├── model
│   ├── Game.java              # состояние партии
│   ├── GamePhase.java         # фазы партии
│   ├── JournalEntry.java      # одна запись журнала
│   ├── NightResult.java       # итог ночи
│   ├── Player.java            # участник партии
│   ├── PlayerKnowledge.java   # знания игрока о других
│   ├── Team.java              # команда: город или мафия
│   ├── Vote.java              # один голос
│   ├── VotingResult.java      # итог голосования
│   └── role
│       ├── NightAction.java
│       ├── NightActionType.java
│       ├── NightActionResult.java
│       ├── Role.java
│       ├── Civilian.java
│       ├── Mafia.java
│       ├── Commissioner.java
│       ├── Doctor.java
│       └── Lover.java
├── service
│   ├── GameService.java       # создание игры и проверка победы
│   ├── NightResolver.java     # ночные действия и конфликты
│   ├── VotingService.java     # подсчёт голосов
│   └── JournalService.java    # журнал и его видимость
└── view
    └── ConsoleView.java       # консольный ввод и вывод
```

Тесты находятся в `src/test/java/com/mafia` и повторяют структуру `model` и `service`.

## Технологии

- Java 17
- Maven
- JUnit 5

## Запуск

Через IntelliJ IDEA:

1. Открыть `pom.xml` как Maven-проект.
2. Запустить `com.mafia.Main`.

Через Maven:

```bash
mvn test
mvn package
```
