# Мафия

Консольная игра на Java по заданию «Мафия: роли, фазы, голосование».

## Что будет реализовано

- роли: мирный, мафия, комиссар, доктор, любовница;
- ночные действия и разрешение конфликтов;
- фазы партии: ночь, утро, обсуждение, голосование, казнь;
- знания каждого игрока о других;
- дневное голосование с перевесом и переголосованием;
- условия победы мафии и города;
- журнал партии глазами каждого игрока.

## Стек

- Java 17
- Maven
- JUnit 5

## Структура

```text
src/main/java/com/mafia
├── Main.java
├── model
│   └── role
├── service
├── exception
└── view
```

## Запуск

Открыть `pom.xml` в IntelliJ IDEA как Maven-проект и запустить `com.mafia.Main`.

## Статус

Проект в разработке.
